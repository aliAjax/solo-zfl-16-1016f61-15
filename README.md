# 活字排版工坊

一个纯前端本地应用（无构建、无依赖，直接双击打开 `index.html` 即可）。

## 功能

### 排版工坊
- 字模库维护：加入字模（字、风格、字号、数量、磨损度）、搜索与风格筛选、删除。
- 手动落字：点选字模后在网格版面点击落字，再次点击取消，也支持拖拽字模到版面。
- 三种纸张（明信片 / 书签 / 方形小笺）、横排竖排、网格间距、作品名。
- 字模用量实时核对，超量红色提示。
- 草稿保存 / 载入 / 删除，PNG 预览图导出，清空版面。

### 校字台
- 粘贴原稿与校样，系统按 **相同字 / 换字 / 增字 / 缺字** 逐处对齐（最长公共子序列算法，连续缺增自动配对为换字）。
- 每处对齐同时显示两侧字符、原文序号和对应的版面格；右侧小版面用色框标出对应格，无法落到格内的在清单中集中列出。
- 每处差异可单独「保留原稿 / 采用校样」，换字可选择具体字模，增字需点选落格；也支持「全部采用校样 / 全部保留原稿」批量裁决。
- 落版前统一核对并逐项拦住：缺字模、**字模数量短缺**、**越界（超出版面容量）**、**位置冲突**（格内现字与原稿不符、两改动指向同一格等）。
- 应用时只改选定的格：其他落字、草稿和版面设置均不动；自动留存本次「校记」（相同/换/增/缺统计、实落增减换格数、起始格、备注、时间）。
- 原稿、校样、对读结果、裁决、未决差异与历次校记全部保存在浏览器本地，刷新后原样恢复。

## 文件

- `index.html` — 页面结构（排版工坊 / 校字台两个视图）
- `styles.css` — 样式
- `app.js` — 全部逻辑与本地存储（localStorage）
